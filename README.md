# TasdikiDocs — public certificate verification

This branch holds only the public certificate verification page, published with
GitHub Pages. It is what a certificate's QR code points at, so that anyone can
check a certificate without installing the app or creating an account.

- Live page: https://abdizovic.github.io/tasdikidocs/verify/
- Source and deployment notes: `web/` on the `main` branch.

Nothing else from the project is served from here.
